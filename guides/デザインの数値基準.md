# デザインの数値基準

「いい感じに」で決めると、AI も人も無難な平均値に寄る。先に**数値**を決めておくと、
出てくるものの顔が変わる。ここは、その数値をためる場所。

判断に迷ったときは、この表の値を渡すところから始める。

## 余白と主役の面積

| 何を | どのくらい |
| --- | --- |
| 何も置かない余白 | 画面の **70〜90%** |
| 主役のかたまり | 画面の **8〜25%** |
| 目がぱっと認識する「かたまり」の数 | **4〜5個**まで |

情報を減らす前に、まず「かたまり」の数を減らす。要素が多くても、
まとめて1つに見えていれば散らからない。

## 色

| 何を | どのくらい |
| --- | --- |
| 全体の色数 | **3色**まで（背景・文字・差し色） |
| 面積の目安 | **70 : 25 : 5** |
| 差し色（ポスター寄りの構成のとき） | 画面全体の **0.8〜2.5%**、または主役の中の **15〜35%** |
| 2色目の差し色を足す場合 | 色のついた面積のうち **10%以下**に抑える |
| グレーの濃淡で系列を見分けられる上限 | **3段階** |

差し色を絞るから、そこが「一番強い場所」になる。増やすとどの色も強くなくなる。
グラフや表も同じで、全体をグレーに沈めて、言いたい部分にだけ色を残す。

## 文字

| 何を | どのくらい |
| --- | --- |
| 見出しと本文の大きさの差 | 大きくとる。差が小さいと全部同じ声に聞こえる |
| 日本語の本文 | **16px** 前後（12px は小さすぎる） |
| 行間 | 文字サイズの **1.6〜1.8倍** |

## 写真

| 何を | どのくらい |
| --- | --- |
| 明るさ | 極端に明るい／暗いものを避ける（白いカードに白い写真は消える） |
| 1ページあたりの読み込み量 | **5MB** 以内を目安に（1枚 200〜300KB） |
