# 実際に使ったプロンプト：モード系アパレルLP

`mode-lunea-lp.png` / `mode-lumina-lp-1.png` / `mode-lumina-lp-2.png` は、このプロンプトで生成したもの。
**「〜にはしない」を明記しているのが効いている。** AI が既定で出しがちな平均値を、名指しで禁じている。

---

高級感のあるモード系アパレルブランドの、縦長のWebランディングページ（LP）デザインを作成してください。

## デザインコンセプト
海外のハイファッションブランド、ファッション誌、ラグジュアリーブランドのキャンペーンサイトを融合したような世界観。
一般的なECサイトのような「商品一覧中心」のデザインではなく、ブランドの世界観を強く感じるアートディレクション重視のLP。
BLACK × WHITE をベースにした、ダークでモード、エディトリアル、シネマティックなデザイン。

## ブランド
- Brand Name: LUNÉA
- Concept: 「自分らしさを、もっと自由に。」
- 20代後半〜30代女性向けの、ミニマルでモードなファッションブランド

## ファーストビュー
画面いっぱいに女性モデルのファッションフォト。黒背景。
濡れたようなウェットヘア。黒〜シルバーの光沢感のある服。強いフラッシュ撮影。映画のワンシーンのような陰影。
写真の上に巨大なタイポグラフィを重ねる。「New Arrival」。文字は白、大胆な手書きブラシ風。
小さく WEAR / YOUR / OWN / STORY と配置。
右上にミニマルなナビゲーション（HOME / COLLECTION / ABOUT）、人物アイコン、ショッピングバッグアイコン。

## SECTION 02
左右50:50の大胆な分割レイアウト。左はモノクロの女性モデル写真、右は完全な黒背景。
大きなセリフ体で FASHION / BEYOND / TRENDS。その下に日本語で「流行に流されない、自分らしいスタイルを。」
VIEW COLLECTION → という細いアウトラインボタン。

## SECTION 03 / NEW ITEMS
一般的な商品カードを並べない。
左側に大きく NEW ITEMS、「纏うたび、気分が上がる。」
右側に、暗いスタジオで撮影した洋服のラック。黒・白・チャコールを中心とした服。
金属製ハンガーラックに強いスポットライト。光と影を強調したシネマティックな商品写真。

## BRAND VALUE
横一列の細長いブラックセクション。シンプルな白いラインアイコンとともに、
PREMIUM MATERIAL（上質な素材）/ TIMELESS DESIGN（時代を超えるデザイン）/
WORLDWIDE SHIPPING（海外発送対応）/ SUSTAINABLE（環境に配慮したものづくり）。

## FINAL CTA
左側に女性モデルの大胆なモノクロクローズアップ写真。右側は黒〜チャコール背景。
「自分らしさ」を、もっと自由に。SHOP NOW → という大きなCTA。

## 全体デザイン
- BLACK / CHARCOAL / WHITE のみ。差し色をほぼ使用しない
- 強いコントラスト / 大胆な余白 / 巨大タイポグラフィ
- セリフ体＋サンセリフ＋手書き文字を組み合わせる
- 写真を画面端まで大胆に使用 / 左右非対称レイアウト / グリッドをあえて崩す
- 文字を写真に重ねる / 細い罫線 / 小さな英字ラベル
- ファッション誌の誌面のような文字組み
- 少しフィルムグレイン / 強いフラッシュ / 深い黒 / 金属やレザーの光沢感
- Webサイトとして実在しそうな UI

## してはいけないこと
「よくあるShopifyテンプレート」「ナチュラルな韓国風EC」「ベージュ系ミニマルLP」にはしない。
商品を売るECサイトというより、ブランドの LOOKBOOK とファッション誌をそのまま Web サイトにしたようなデザイン。
縦長のフルLPを1枚のWebデザインカンプとして表示。

---

## なぜこれが効くのか

1. **禁止を名指ししている** — 「Shopifyテンプレートにはしない」の一行が、平均値への逃げを塞いでいる
2. **セクションごとに指示を分けている** — 全体の雰囲気だけでなく、各セクションの構図まで指定している
3. **撮影条件まで書いている** — 「強いフラッシュ」「ウェットヘア」「金属の光沢」など、
   写真の質感を言葉で決めている。ここが曖昧だとストック写真的な絵になる
4. **文字組みの様式を指定している** — セリフ体・サンセリフ・手書きの3種を組み合わせる、と決めている

業種を変えて使い回すときは、**ブランド名・コンセプト・写真の質感・禁止事項**の4か所を書き換える。
