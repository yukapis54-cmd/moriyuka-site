## してはいけないこと
普通のアパレルECテンプレートにしない。
「写真 → テキスト → 商品カード → テキスト」だけの単調なLP構成にしない。
セクションごとにレイアウトを変える。写真を少し傾ける。文字を写真に重ねる。
ステッカーをはみ出させる。手書き文字を混ぜる。背景を途中からピンクにする。曲線でセクションを区切る。
整いすぎない「計算されたかわいさ」を作る。

## モード系と比べて分かること

この2つは、**書いている項目はまったく同じ**。中身を入れ替えているだけ。

| 項目 | モード系（LUNÉA） | ガーリー系（mellty） |
| --- | --- | --- |
| 色 | 黒・チャコール・白のみ。差し色なし | パステル多色。黒はほとんど使わない |
| 写真 | 強いフラッシュ、深い影、金属の光沢 | 柔らかい自然光、透明感 |
| 文字 | セリフ体＋サンセリフ、巨大 | 丸みのある手書き、ステッカー |
| 構図 | 左右非対称、グリッドを崩す | 傾ける、はみ出す、曲線で区切る |
| 禁止 | Shopifyテンプレ、韓国風EC、ベージュ系ミニマル | 普通のECテンプレ、単調な縦積み |

つまり業種やトンマナが変わっても、**書くべき項目は同じ**。
ブランド / 色 / 写真の質感 / 各セクションの構図 / してはいけないこと、の5つを埋めればいい。

そして両方に共通して効いているのが、**最後の「してはいけないこと」**。
ここを書かないと、AI はどちらのブランドでも同じような無難な画面を返してくる。
