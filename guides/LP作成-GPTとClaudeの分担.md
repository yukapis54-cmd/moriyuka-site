# LP を作る手順（GPT Image 2 で絵 → Claude で素材 → Claude Design で実装）

AI に「LP を作って」と丸投げすると、いかにも AI が作った画面になる。原因は**素材が無いこと**。
本来デザイナーから渡ってくる透過素材（背景の図形、アイコン、ロゴ）を用意してから実装させると、
同じ AI でも仕上がりが変わる。

手順は4つ。1と2は ChatGPT、3はこのリポジトリのスクリプト、4は Claude Design。

---

## 1. LP のデザイン画像を1枚作る（ChatGPT / GPT Image 2）

画像生成モードで、下のプロンプトの ★ を自分の内容に差し替えて投げる。

**トンマナ（トーン&マナー）の指定が、出来上がりに一番効く。** ここは面倒がらずに言葉を重ねる。

```
ランディングページのデザインカンプを1枚の縦長画像で作ってください。

# 前提
- 目的: ★問い合わせを増やしたい（商品を売りたい／世界観を伝えたい／ファンを増やしたい）
- 業種: ★愛媛の離島の水産加工（天然なまこ）
- ターゲット: ★贈り物に確かなものを選びたい40〜60代
- 読み終えた時の状態: ★「ここに頼めば間違いない」と思っている

# トンマナ（ここを一番具体的に）
- ★静かで、上質。余白が多い。落ち着いた明朝の見出し
- ★色は3色まで。生成り × 墨 × 差し色に金を少しだけ
- ★写真は自然光、彩度低め、影が柔らかい
- 避けたいもの: ★安っぽいグラデーション、ドロップシャドウ、過剰な装飾、ストック写真的な笑顔

# デザイン要件
- ファーストビュー、特徴3点、商品/サービス、作り手の紹介、お客様の声、問い合わせ、フッターの順
- 見出しは日本語。ダミーテキストも日本語で、意味の通る文にする
- 全部を同じ強さで見せない。一番見せたいものを強く、次を少し弱く、それ以外はもっと弱く
- 目がぱっと認識する「かたまり」は4〜5個まで
- 要素の左端は揃える。ただし主役の写真か大きな文字は1つだけあえて外して目立たせる
- 背景に、不規則で柔らかい抽象図形を敷く（大きく、薄く、一部だけ）
- 余白は要素より多めに

# 禁止
- 意味のないダミー英文（Lorem ipsum）
- 根拠のない「最高品質」「業界No.1」
- 文字の上に読みにくい写真を敷くこと
```

うまくいかない時は、トンマナの行を増やす。要素を足すより効く。

## 2. 素材シートを2枚出す（同じ ChatGPT の会話で続けて）

**生成した画像を選択した状態で**、続けて投げる。1枚目は背景・装飾、2枚目はロゴ・アイコン。

**「正方形」「ピクセル単位を揃える」を必ず入れる。** これが無いと 3 の切り出しがずれる。

```
このLP画像で使われているWebデザイン用の素材を、1枚の画像にまとめて抽出してください。

- 4列 × 4行の均等なグリッドに配置する
- 1マスは正方形で、すべて同じピクセルサイズに揃える
- グリッドの線や余白のズレが出ないよう、マス目の境界をピクセル単位で正確に揃える
- 素材同士は重ねず、1マスに1つだけ独立して置く
- 背景は純白（#FFFFFF）の単色にする。影やグラデーションを敷かない
- 対象: 背景に使われている抽象図形、装飾、あしらい、区切り線
```

続けてもう1枚：

```
同じ形式（4×4の正方形グリッド、純白背景、1マス1素材、ピクセル単位で正確に）で、
抽象図形や装飾以外の素材も取り出してください。
対象: ロゴマーク、アイコン、ピクトグラム、イラスト
```

## 3. 素材シートを1枚ずつに分割して透過する（このリポジトリ）

ダウンロードした素材シートを、このコマンドに渡す。

```bash
node scripts/split-sheet.mjs ~/Downloads/素材シート.png --cols 4 --rows 4
```

- `.lp-assets/素材シート/` に `01.png` 〜 `16.png` が出る
- **白背景は自動で透過**する（四隅から白の領域を辿って抜く。図形の中の白は残る）
- 中身が空のマスは自動で捨てる
- ずれている時は `--trim 8` で各マスの外側を8pxずつ削る

## 4. Claude Design で実装させる

新規プロジェクトを作り、次を**全部**渡す。

- 1 で作った LP デザイン画像
- 3 で出力した `.lp-assets/**/*.png`（フォルダごとドラッグ&ドロップ）

指示はこれだけでいい。

```
渡したLPのデザイン画像と素材を元に、忠実にランディングページを実装してください。

- 素材のPNGは、デザイン画像の中で使われている位置と大きさに合わせて配置してください
- 写真部分はフリー素材に差し替える前提で、プレースホルダーにしてください
- スマートフォンを優先して設計してください
```

直すときは Claude Design のコメント機能で該当箇所を指して伝える。
細かい調整とデプロイは Claude Code に持っていく（右上の Share → Claude Code でコマンドをコピー）。

## AI感を消す（ここが本題）

同じ指示で30通り作って分かったこととして、**AI感の正体は画力ではなく「判断の丸投げ」**だと言われている。
「いい感じに作って」と投げると、AI は無難な平均値を返す。だから参照先を1つ渡すだけで顔が変わる。

効く順に並べると、こうなる。

1. **デザインシステムのトークンを渡す** — いちばん効く。色・角丸・余白・文字サイズの数値を先に決めて渡す。
   自分で決められないなら[デジタル庁のデザインシステム](https://www.digital.go.jp/policies/servicedesign/designsystem)を下敷きにする。
   これだけで、AI が好んで出す紫っぽい配色と過剰な角丸が消える
2. **参照するデザインを1つ渡す** — 手本の画面を渡して「この通りに」と言う。この手順書の 1〜4 がまさにこれ
3. **様式と質感を名前で指定する** — 「明朝の大見出し」「フィルムグレイン」「オフセット印刷風のハーフトーン」など、
   様式に名前をつけて渡す。曖昧な形容詞より効く
4. **写真と動画で実在感を出す** — ストック写真をやめて、自分で撮った写真を入れる
5. **動きをつける** — スクロールに連動した動き。ただし技術的な手間は増える

### 写真は、どこまで AI でいいか

全部を撮り直す必要はない。**分けて考える。**

| 用途 | AI 生成 | 理由 |
| --- | --- | --- |
| 営業用のサンプル、架空の店 | **AI でよい** | 実物が存在しないので、撮りようがない |
| 背景、質感、抽象的なイメージ | **AI でよい** | 誰の何とも紐づかないので問題にならない |
| 実際に売る商品そのもの | **実写にする** | 下の2つの理由 |

商品写真を実写にする理由は2つ。

1. **信用** — 全部きれいに作れてしまうと、どこが本物か分からなくなって、見る側が先に信用をやめる
2. **表示規制** — 実際に届くものと違う見栄えの生成画像を商品写真として出すと、景品表示法の
   優良誤認にあたる可能性がある。食品や一次産品は実物との差が出やすいので特に注意

現実的な折衷案は「**商品そのものは実際に撮った写真を使い、背景だけ AI に作らせる**」。
手間は最小で、リスクもない。

### 今日すぐできる一手

**写真を1枚、ヒーローの背景に敷く。上に黒の半透明（スクリム）を重ねて、白文字を置く。**
これだけで、他のどの小細工よりも AI 感が落ちる。背景用なら生成画像で構わない。

## つまずきやすいところ

| 症状 | 原因と対処 |
| --- | --- |
| 切り出した素材がずれる・欠ける | グリッドが正方形になっていない。2 のプロンプトで「ピクセル単位で正確に」を強調して出し直す |
| 透過されない | 背景が純白でない（薄いグレーや影がある）。`--tolerance 40` を上げる |
| 実装が素材を使ってくれない | 素材を渡し忘れているか、枚数が多すぎる。使ってほしいものだけ10枚程度に絞る |
| AI感が抜けない | 素材ではなく写真の問題。人物と商品の写真を自分で撮って差し替える |

Claude Design はプレビュー版で**週あたりの利用制限が厳しい**。試行錯誤は Claude Code 側でやるほうがいい。
