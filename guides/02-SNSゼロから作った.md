# SNSを0から作った
〜フォロワー0から6ヶ月で1.6万人超・月間105万回再生を実現した、発信の始め方〜

こんにちは、もりゆか（森結花）です。

私は愛媛の小さな離島の出身で、もともとは大阪のIT企業で働いていました。年収600万円、いわゆる「安定」した会社員。そこを脱サラして、島へUターンし、実家の天然ナマコ事業に飛び込みました。

ここで先に言っておきたいことがあります。**私はプログラミングが一切できません。** コードの「コ」の字も書けない、ど真ん中の非エンジニアです。それでも、AIを相棒にすることで、SNSをゼロから立ち上げて6ヶ月でこんな結果になりました。

- SNS総フォロワー **16,400人超**
- 月間 **105万回再生**
- ホームページもない状態から、1人で自社EC（[setouchi-seafood.com](https://setouchi-seafood.com)・天然ナマコ）を立ち上げて **100セット以上を販売**

このガイドは、「離島のナマコ」みたいなニッチな商売でも伸びたんだから、あなたにもきっとできる——そんな希望を渡すために書いています。専門用語は使いません。一緒に、最初の一歩から見ていきましょう。

## 1. 0スタートだった頃の話

最初は本当に何もありませんでした。フォロワー0人、ホームページなし、撮影機材なし、知識なし。あるのは「島の天然ナマコ」という商品と、スマホ1台だけ。

正直、最初は怖かったです。「誰も見てくれなかったらどうしよう」「島のおばちゃんに笑われたら」。でも、やってみて分かったのは——**最初の数字がしょぼいのは全員同じ**だということ。誰もが0から始めます。

> ［要記入：投稿を始めて最初の1ヶ月のリアルな数字（フォロワー・再生数）と、その時の気持ち］

大事なのは「完璧に準備してから始める」のではなく「始めてから直す」こと。これがすべての土台です。

## 2. どの媒体から始める？

私は今、**8つのSNS**を運営しています。

> Instagram / Facebook / TikTok / YouTube / Threads / note / LINE公式 / Substack

でも、**最初から8つやったわけではありません。** いきなり全部に手を出すと、必ずパンクします。

### 最初の1つの選び方

選ぶ基準はシンプルに3つ。

1. **あなたが続けやすい形式か**（文章が得意なら note、話すのが得意なら動画系）
2. **お客さんがいる場所か**（年齢層・興味で媒体は変わる）
3. **伸びやすさ**（今は短尺動画＝リール/TikTok/YouTube Shortsが圧倒的に拡散しやすい）

迷ったら、まずは短尺動画から。理由は、フォロワー0でも「おすすめ」に乗れば一気に届くからです。

> ［要記入：もりゆかが最初に始めた媒体と、その理由］
> ［要記入：今いちばん伸びている媒体／それぞれの媒体の使い分け方］

ポイントは、**1つの動画を作ったら複数媒体に使い回す**こと。1回の撮影で何倍も働いてもらいます。

## 3. アカウント設計：「何の人か」を一瞬で伝える

伸びる人は、プロフィールを見た瞬間に「あ、この人はこういう人だ」と分かります。逆に伸びない人は「結局、何の人なの？」となりがち。

私のアカウントは「**離島でナマコを売る、元IT会社員。AIを使って1人で事業をやってる人**」と一言で言えるようにしています。肩書きは欲張らず、1〜2個に絞るのがコツです。

プロフィールに入れたい要素はこの3つ。

- **何をしている人か**（例：離島でナマコのEC運営）
- **誰に向けて発信しているか**（例：脱サラして地方で個人事業をしたい人）
- **フォローすると何が得られるか**（例：非エンジニアでもAIで事業を作る方法）

> ［要記入：もりゆかの実際のプロフィール文（各SNSで使っている自己紹介）］

アイコンと「最初に見える1行」だけで勝負が決まります。ここは時間をかけて何度も書き直してOKです。

## 4. 伸びる投稿の「型」

短尺動画には、伸びる「型」があります。私も最初は感覚でやっていましたが、型を意識してから一気に再生数が伸びました。

### 基本の型

1. **冒頭2秒で心をつかむ**（「離島でナマコ売って月◯◯」みたいに結論や意外性を最初に）
2. **共感 or 問題提起**（「会社辞めたいけど不安ですよね」）
3. **中身**（具体的なノウハウ・実演・ビフォーアフター）
4. **締め＋次の行動**（「続きはプロフィールから」「保存してね」）

特に**冒頭2秒**がすべてです。ここでスワイプされたら、どんな良い中身も見てもらえません。

> ［要記入：いちばん伸びた投稿の具体例（テーマ・再生数・なぜ伸びたと思うか）］
> ［要記入：使っている撮影・編集アプリ名］

凝った編集より、「**最初の一言**」と「**分かりやすさ**」。これだけで十分戦えます。

## 5. AIの使い方：ここが私の最大の武器

非エンジニアの私が回せている理由は、ほぼこれです。AIを「優秀なアシスタント」として使い倒しています。

### ① ネタ出し

「ナマコの発信ネタを20個出して」とお願いするだけで、自分では思いつかない切り口が出てきます。ネタ切れの不安がなくなります。

### ② 台本・構成

出てきたネタを、さっきの「伸びる型」に当てはめて台本にしてもらいます。「冒頭2秒で引きの強いフックを5パターン」みたいに頼むのも効果大。

### ③ リサーチ

「離島で個人事業をする人が知りたいことは？」と聞けば、読者の悩みを整理してくれます。お客さん理解が一気に進みます。

> ［要記入：もりゆかが実際に使っているAIツール名（複数あれば全部）］
> ［要記入：よく使っているプロンプト（指示文）の具体例］

コツは、**AIに丸投げしない**こと。出てきた案を、自分の言葉・自分の体験で味付けする。AIは8割を高速で作り、最後の「あなたらしさ」は人間が乗せる。この役割分担が一番うまくいきます。

## 6. 続けるコツと1日のルーティン

SNSは「才能」より「続けられるか」で差がつきます。1人事業だと時間も限られるので、**仕組み化**が命です。

私が意識していること:

- **完璧を目指さない**（60点で出す。出さなきゃ0点）
- **作業をまとめる**（撮影日・編集日をまとめて、毎日ゼロから考えない）
- **AIに前段を任せる**（ネタ出し・台本で時間を短縮）

> ［要記入：もりゆかの実際の投稿頻度（各媒体・週何本など）］
> ［要記入：もりゆかの1日のおおまかなスケジュール／作業時間］

「毎日完璧に」より「**無理なく長く**」。半年続けられる人が、結局いちばん伸びます。

## 7. つまずいた所と、乗り越え方

正直、順風満帆ではありませんでした。

- 投稿しても全然伸びない時期
- 何を発信すればいいか分からなくなった時期
- 1人で全部やる大変さ

> ［要記入：もりゆかが実際にいちばん心が折れかけた失敗談と、そこからどう立て直したか］

私が乗り越えられたのは、**数字に一喜一憂しすぎず、改善を淡々と続けた**から。伸びない投稿も「次の改善材料」と思えば、失敗じゃなくなります。

そして、行き詰まったらAIに相談していました。「この投稿が伸びなかった理由を3つ挙げて」と聞くだけでも、一人で抱え込まずに済みます。
