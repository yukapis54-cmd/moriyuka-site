# 未経験の私が、自分の公式サイトを公開するまでの全手順

— プログラミングが一切できない非エンジニアの私が、AIを相棒に「自分の家（公式サイト）」をネットに建てるまで

こんにちは、もりゆかです。愛媛の離島で実家の天然ナマコ事業をやりながら、「島暮らし1人事業」を発信しています。

正直に言うと、私はコードが**一切**書けません。`<html>` が何かもつい最近まで知りませんでした。それでも、今あなたが見ているこの公式サイトは、ぜんぶ私がAIと日本語で話しながら0から作ったものです。

「サイトなんて自分には無理」と思っていた私でも、最後まで行けました。この記事では、その全手順を、専門用語をできるだけ使わずに正直に書きます。

---

## やることは、たった6ステップ

最初に全体像です。難しそうに見えても、やることはこの6つだけ。

1. **作りたいものを言葉で決める**（どんなサイトが欲しいか）
2. **AIに頼んでページを作ってもらう**（小分けで指示）
3. **自分のパソコンで確認して、修正をお願いする**
4. **コードを保管庫（GitHub）に入れる**
5. **公開する土地（Vercel）につないで、ネットに出す**
6. **もらえたURLで確認＝完成！**

これだけです。しかも一度公開してしまえば、あとは**更新を保存して送る（push する）だけで、自動で世界に反映**されます。順番に見ていきます。

---

## ステップ1〜6を、具体的に

**1. 作りたいものを言葉で決める**
まず「誰に・何を伝えるサイトか」を自分の中で決めます。私の場合は「自己紹介・実績・メルマガ登録・お問い合わせがある1ページのサイト」でした。図やデザインは要りません。言葉だけでOKです。

**2. AIに頼んでページを作ってもらう**
私が使ったのは Claude Code というAIコーディングツール。**日本語で会話するだけで、コードを書いてサイトを作ってくれます**。デザインも文章も、対話しながら一緒に進みます。ここで一気に頼まず、小分けにするのがコツ（後述）。

**3. 自分のパソコンでプレビューして確認・修正依頼**
作ってもらったサイトは、公開前に自分のパソコンで見られます。「ここの余白を広く」「写真をもっと大きく」など、気になった所をそのまま日本語で伝え直します。

**4. GitHub にコードを保管**
できたコードは GitHub（コードの保管庫）に入れます。難しい操作はAIが手順を案内してくれるので、言われた通りにするだけ。

**5. Vercel につないで公開**
保管庫を Vercel（サイトを公開する土地）につなぐと、ネットに出ます。すると `◯◯.vercel.app` のような**無料の住所（URL）**がもらえます。

**6. 自分のURLで確認＝完成**
もらったURLをスマホで開いて、ちゃんと見えたら完成です。世界中の誰でも、もう見られます。

## 誰が、何をやってくれるのか

ツールがいくつか出てきて混乱しそうですが、役割で覚えると一気にスッキリします。

| 道具 | 役割 | たとえると |
|---|---|---|
| **Claude Code** | サイトを作ってくれるAI | **作る職人** |
| **GitHub** | コードを保管する場所 | **コードの保管庫** |
| **Vercel** | ネットに公開する場所 | **公開する土地** |

職人（Claude Code）が家を建て、保管庫（GitHub）に設計図をしまい、土地（Vercel）に建てて公開する。この3つだけ押さえれば大丈夫です。

さらに、サイトを「動く家」にするために、私はこんな機能を付けました。どれも「○○を付けて」とAIに頼むだけで、自分でコードを書く場面はありませんでした。

- **メルマガ登録**（Kit）：読者と直接つながる命綱
- **お問い合わせフォーム**（Web3Forms）：仕事の依頼が届く窓口
- **アクセス解析**（Vercel Analytics）：何人が・どこから来たか分かる
- **SNSリンク**：各アカウントへの導線

## なんでこれ使ってるの？（ツールを選んだ理由）

- **Claude Code を選んだ理由**：とにかく**日本語の会話だけ**で進むから。コードの知識がいらず、「もっと優しい雰囲気に」みたいなふわっとした注文も通じます。非エンジニアの私にはこれが一番でした。
- **Vercel を選んだ理由**：**無料の範囲で公開できて**、URLまでもらえるから。お金をかけずに「まず出す」がすぐできました。
- **Kit / Web3Forms を選んだ理由**：どちらも無料で始められて、設定がシンプルだったから。メルマガも問い合わせも、最初から大きく作り込まなくていいんです。

結果として、かかった費用は**ほぼ0円**（使ったのは無料ツールだけ）、期間は**約1ヶ月**でした。

## AIへの「頼み方」が、いちばん大事

ここが正直、一番の核心です。上手に頼めれば、ほぼ完成したも同然です。

- **ゴールを先に伝える**：「自己紹介・実績・メルマガ登録・問い合わせがある1ページが欲しい」と、完成形を最初に言う。
- **専門用語は要らない**：「青っぽくて、写真が大きくて、スマホで見やすく」で通じます。素人の言葉のほうが正確に伝わることも多いです。
- **一度に全部やらない**：大きく頼むほど迷子になります。小分けが正解。
- **気に入らなければ言い直す**：「もっと余白を」「この文章を優しいトーンに」。何度でもやり直せます。怒られません（笑）。

私の実際の頼み方はこんな感じでした。最初に **「愛媛の離島で実家の天然ナマコ屋をやっています。脱サラ・島暮らし・SNS発信が伝わる1ページの公式サイトを作って」** とゴールを伝え、そこから **「トップを自分の写真に」「メルマガ登録を付けて」** と、少しずつお願いしていきました。

## 最初にハマりやすいところ

スルッとは行きませんでした。でも、全部乗り越えられます。私が実際につまずいた3つです。

**① 写真・素材が足りない**
これが一番大変でした。商品写真やイメージ写真が手元に少なく、足りない分を探して集めるのに苦労しました。→ 自分で撮った写真をできるだけ使い、不足分は**商用利用OKの無料素材**で補いました。「まず手持ちで始めて、後から差し替える」でOKです。

**② SEO（検索で見つけてもらう工夫）に悩む**
作っただけでは、検索しても出てきません。タイトルや説明文の付け方で頭を悩ませました。→ ここもAIに「検索で見つけてもらうにはどうすればいい？」と相談しながら、少しずつ整えました。

**③ 表示が思い通りにならない**
スマホで余白が変、画像が大きすぎる…等。→ **そのまま日本語で言い直すだけ**で直りました。これが非エンジニアの最強の進め方です。

## 自分のドメインで出したくなったら

私は今のところ、もらえた無料の住所（`◯◯.vercel.app`）のまま運用していて、独自ドメインはまだ取っていません。その分、費用は0円です。

もし「自分だけの住所（例：あなたの名前.com）」が欲しくなったら、独自ドメインを取得して後から設定できます。最初から無理に取らなくて大丈夫。**まず無料で公開して、必要になったら足す**——この順番でいいと思います。
